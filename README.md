# BEE Virtual Lab

An interactive simulator for Basic Electrical Engineering, made as a capstone project.

**Modules**
1. Thevenin's, Norton's and Maximum Power Transfer theorems
2. Mesh, Nodal Analysis and Superposition
3. Star ↔ Delta transformation
4. Series RLC circuit and resonance
5. Balanced three-phase systems and the two-wattmeter method
6. Single-phase transformer: efficiency and regulation
7. DC generator and motor: EMF, speed and torque
8. Three-phase induction motor: slip and torque–slip characteristic

**Features:** live animated circuit diagrams, step-by-step solutions, interactive graphs and built-in verification checks.

**Tech:** plain HTML, CSS and JavaScript in a single `index.html` file, with no libraries and no build step. Open `index.html` in any browser to run it.
